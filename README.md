# Digital Resume & Minimalist Portfolio Card

A personal, ultra-minimalist, monochrome digital resume card portfolio built with React, Vite, and Tailwind CSS. Designed for high performance, accessibility, and direct technical disclosure without decorative clutter.

## Features & Architecture

* **Monochrome Visual Identity:** Clean black-and-white layout focusing on typography, whitespace, and precise monospace metadata.
* **Interactive Case Study Modal:** Deep-dive project breakdowns (Problem, Solution, Key Highlights) with keyboard [Esc] and backdrop dismiss capabilities.
* **Responsive Tabbed Interface:** Modular tab system (01. ABOUT, 02. PROJECTS, 03. CONTACT) with horizontal scroll support for mobile devices.
* **Instant Interaction Utility:** One-click email clipboard copy functionality with real-time UI status feedback.
* **Dynamic Dark/Light Mode:** Seamless theme toggling backed by localStorage persistence and system root class synchronization.
* **Analytics & Performance Tracking:** Integrated with Vercel Analytics and Vercel Speed Insights for real-time monitoring.

## Tech Stack & Ecosystem

* **Frontend Library:** React.js (v18+)
* **Build Tooling:** Vite
* **Styling & Design System:** Tailwind CSS
* **Typography:** Inter (Sans-serif) & JetBrains Mono (Monospace)
* **Analytics & Telemetry:** @vercel/analytics, @vercel/speed-insights
* **Deployment Platform:** Vercel
